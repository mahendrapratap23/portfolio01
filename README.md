## ✨ Key Features

- 🎨 **Minimalist Editorial Aesthetics**: Bold kinetic typography, micro-interactions, magnetic hover effects, and custom mouse cursor.
- 🌓 **Dark / Light Mode System**: Instant theme toggling backed by custom CSS variables (`--bg`, `--fg`, `--border`).
- 📁 **Interactive Case Study Modals**: Clickable project cards opening modal drawers with technical highlights, tech stacks, and direct repository links.
- 📄 **Resume / CV Integration**: Quick PDF resume download accessible from Navigation, Hero section, and Contact section.
- ✉️ **Interactive Contact System**: Direct `mailto` email integration with instant clipboard copy toast notification.
- ⚡ **Zero-Dependency Architecture**: Built purely with vanilla HTML5, CSS3, and modern ES6 JavaScript.
